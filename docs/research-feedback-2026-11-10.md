# 研究端教師回饋調整

本輪以研究資料取得與閱讀為主，依教師回饋精簡畫面。調整入口為 `/research-tools`。

| 回饋 | 調整 |
| --- | --- |
| 研究端不用音樂 | 所有研究路由與舊網址停用背景音樂，從其他頁進入時會停止既有播放。 |
| 縮寫不易對應中文 | 中文作業名稱在前、代碼在後。六作業說明補上英文名稱與代碼來源；SRT、LB 說明沿用舊代碼的原因。SRT 名稱改為「反應抑制」，涵蓋水果測驗與橡實訓練。 |
| 資料難以閱讀 | 總覽前段提供「逐題作答資料」「場次摘要」「欄位說明」CSV，另有可搜尋、排序及分頁的逐題預覽。 |
| 說明過多 | 移除重複用途宣告、未啟用的臨床監測文字及操作提示。方法、限制、代碼對照與完整檔案可按需展開；模擬資料與真實資料的識別仍保留。 |
| 箱型圖與離群值過於顯眼 | 分布、箱型圖與離群值預設收合；主畫面保留缺漏數與描述統計。0 或 1 筆有效場次不畫分布／箱型圖，並明列有效場次數。 |

## 匯出約定

- 逐題作答資料一列對應一筆原始採集紀錄，只讀取 `rawTrials`；不把清理後的作答或推估數值補入原始欄位。
- 共用欄位包含參與者與場次代碼、中文作業名稱、作業代碼、模式、測驗版本、難度、規則、題次、刺激、預期／實際作答、正誤、反應時間、逾時與來源題次鍵。
- 各作業已記錄的額外欄位分開展開；陣列與事件保留於各自的 JSON 儲存格。原始完整 JSON 與原有研究分析檔仍可由進階下載取得。
- 空白代表來源未記錄；`false`、`0` 與空陣列保留。數值單位與來源寫於欄位說明，場次摘要正確率為百分比。
- 常用 CSV 下載附 UTF-8 BOM，便於 Excel 顯示中文。預覽搜尋與排序只影響畫面，匯出以共用參與者與作業範圍為準。
- 匯出保留原本的研究 UUID；本機顯示的 P 編號不取代研究識別碼。只展開明列的採集欄位，不自動攤開未知來源中的姓名、信箱等欄位。

本輪未變動遊戲規則、採集資料、資料庫、清理排除規則、模型與統計計算；既有完整匯出維持原格式。
