# LB 正式測驗前的兩段試玩

已整合至 `src/pages/TestPage_LB.jsx`，不需要新增路由。試玩與正式測驗共用同一次選定的副本：01 淺灰／深灰石頭、02 紅／紫信箱；landmark 專用於 training。沿用背景、小屋及按鈕；開始畫面以 `LB_icon.webp` 放大裁切素材內建透明邊緣，填滿圓形框。試玩與正式作答底部只保留移除／送出按鈕，不顯示進度數字或說明文字。

## 狀態切換與核心邏輯

```text
開始 → STEP（播完、跳過或下一步）
     → practiceMode1：第一色 1 → 2 → 3 → 4 → 5
     → practiceMode2：第一色 1 → 第二色 2 → 第一色 3 → 第二色 4 → 第一色 5 → 第二色 6
     → formalMode：原本的兩段正式測驗
```

每段試玩都必須由幼兒完整選取並按「送出答案」。逐項比對木牌 key，同時檢查數字、顏色及順序；送出後會共用正式測驗的 `walk.webp` 動畫，沿本次選取順序前進。全對時奶奶走回小屋，動畫結束後播放完成語音，播畢再自動切換下一段；錯答路線播放完後先恢復路牌顯示，再播放重試語音並亮起提及路牌，播完才恢復作答，保留選取供修改。動畫及重試語音期間鎖住操作，不寫入成績。

兩段試玩共用 `handleNumberClick`、`handleUndoLastSelection` 與 `handleSubmitStage`。移除會取消最後一張；再次點擊已選取木牌，也保留原本取消該木牌的操作。未選足指定數量時，送出按鈕維持停用。

已點選的路牌以持續金色亮光表示，不顯示勾號；取消選取或移除後恢復一般外觀。試玩及正式測驗共用這項選取回饋，與答案是否正確無關。

「移除」與「送出答案」使用相同寬度及 8:5 顯示框，按各自原圖的透明留白裁切顯示，使圖案本身與點擊區域一致大；桌面與手機共用尺寸規則。棋盤底部依按鈕高度保留空間，避免路牌與按鈕重疊。

## 音效時機

所有測驗語音取自 `src/asset/voice/LB_副本`，完整檔名與事件對應以 `src/config/lbAssessmentConfig.js` 為準。

| 時機 | 01 石頭 | 02 信箱 |
| --- | --- | --- |
| 試玩一規則 | 看看石頭上的數字，從一開始照順序點 | 看看信箱上的數字，從一開始照順序點 |
| 試玩二規則與示範引導 | 淺灰石頭 1、深灰石頭 2、淺灰石頭 3 | 紅信箱 1、紫信箱 2、紅信箱 3 |
| 試玩二顏色錯誤 | 淺灰色、深灰色要輪流點 | 紅色、紫色要輪流點 |
| 正式規則一 | 從一開始，看看石頭上的數字，照順序點 | 從一開始，按照信箱上的數字，照順序點 |
| 正式規則二 | 從淺灰石頭 1、深灰石頭 2 開始，數字與顏色交替 | 按照數字順序點，信箱顏色也要記得換 |

共用事件：開場「一起來幫綿羊奶奶找到回家的路吧！」、換手「從數字一開始，換你試試看！」、試玩二開場「準備好了嗎？看仔細，開始囉！」、數字錯誤「再看看喔！數字要照順序！」、錯答重試「沒關係，我們重新開始試試看！」、5 秒閒置提醒「換你囉！」、試玩成功「太棒了！你學會怎麼玩了！」、正式完成「完成囉！謝謝你幫綿羊奶奶找到回家的路！」。

試玩數字與顏色同時錯誤時先提示數字；取消已選木牌、移除及正確點擊不新增錯誤語音。提醒在每次選牌、移除、錯答送出或點擊空白處後重新計時。每個停頓區間只提醒一次；下一次操作後重新啟用。提醒不顯示滑鼠，操作時停止尚未播完的提醒或錯誤語音，避免重疊。

正式評測作答中不提供數字、顏色、閒置或重試語音，也不顯示答案指引。正式完成與試玩成功使用各自錄音。

正常情況依 `ended` 事件接續，播放錯誤或 autoplay 被拒絕時繼續流程；無法取得媒體資訊時以 12 秒保護性逾時，取得長度後則等待至少錄音長度加 3 秒，避免截斷超過 12 秒的副本語音。切換試玩、進入正式測驗或離開頁面時，會停止舊語音並取消計時器。

## 小雞與語音路牌提示

使用張嘴的 `src/asset/chicken.webp` 與閉嘴的 `src/asset/chicken01.webp`。實際收到錄音的 `playing` 事件才顯示小雞，兩張圖以固定比例重疊、階段式交替顯示，搭配輕微搖擺形成說話動畫；結束、暫停、播放失敗或取消時移除動畫與小雞，不留下額外計時器。

小雞依可用畫面空間放大：試玩一的側欄最高 480px、試玩二 420px、正式規則 380px，另受視窗寬高限制；路牌保留獨立區域。手機直向改為上方大圖、下方路牌，避免側欄壓縮路牌寬度。結果畫面擴大容器並保留獨立小雞欄位，不覆蓋小屋或按鈕。

正式兩關在開場說明結束、小雞消失並開放作答時，移除側欄或手機上方預留區，棋盤擴展到全畫面的作答空間。10／20 張路牌隨機分配到橫跨畫面左右及上下的分離位置，右下角留給小屋、底部留給操作按鈕；每關只分配一次，語音、選取、移除、等待與路線回放不會重新洗牌。正式數字順序、顏色規則及計分維持原流程。

試玩開場「一起來幫綿羊奶奶……」及試玩二開場「準備好了嗎？看仔細，開始囉！」沒有指定路牌，播放時先隱藏路牌、小屋及操作圖示，改為畫面正中間的大隻小雞（最高 960px，按視窗縮放）。進入數字或顏色規則說明時恢復圖示，小雞回到保留區域；語音開放作答前仍維持操作鎖定。

語音提到「從一開始」時對應第一張目標牌；「黃色的一、藍色的二」依序亮起各自路牌，未提到的干擾牌不發亮。使用錄音的 `currentTime`、`timeupdate` 與 `seeked` 更新，暫停或緩衝不會用牆上時間繼續跑提示。現有錄音的路牌時間點集中於 `lbVoiceGuide.js`，更換錄音時需一併校正；不包含特定路牌的開場、閒置、錯誤或完成語音只顯示小雞。

語音提示不會將木牌設為已選，也不寫入成績。正式評測只在開場說明期間亮牌，開放作答前清除提示；作答中仍不提供正解提示。示範手指移動時也會亮起目前指向的單張路牌。減少動態效果設定會停用小雞搖擺、張閉嘴及路牌縮放，保留靜態小雞與亮光。

## mouse 示範

使用既有 `src/asset/mouse.webp`。手指直接出現在第一張示範路牌旁，不從左下角進場；之後依木牌的百分比位置，以 `left/top` 的 650ms CSS transition 在示範路牌間移動，並用 550ms 縮放動畫模擬按下，木牌同步發光。

試玩一示範黃色 1，試玩二示範黃色 1、藍色 2。依使用者確認，示範完成會清空示範選取，讓幼兒自行從頭完成整段；示範期間不能作答。換手語音播放前隱藏滑鼠，正式作答不顯示答案指引。

木牌隨機分配到互相分離的散點位置，同一段操作期間保持位置固定，右下角留給小屋；尺寸隨螢幕寬高縮放。

## 驗證與預覽

```powershell
npm test -- --watchAll=false --runInBand --runTestsByPath src/pages/lbPracticeFlow.test.jsx src/pages/lbProtocolTiming.test.jsx src/utils/lbClinicalMetrics.test.js
npm run check:assets
npm run build
```

本機開發預覽：`http://localhost:3000/test-linking-balloons?gameTesting=1`。此參數使用專案既有的臨時測試隔離，不會儲存兒童正式結果。按「開始」後可看完或跳過 STEP，直接測試兩段試玩。

自動化測試驗證互動、音訊事件、小雞獨立區域、逐牌發亮、暫停與快轉、語音期間鎖定與計時隔離、錯誤與重試、正式作答安靜及離頁取消播放。39 項測試、素材檢查及核心程式 ESLint 已通過；工具目前沒有可用瀏覽器，尚未進行實際版面與聽音同步驗收。
