## 已執行的安全優化

| 項目 | 原因 | 效益 | 風險與回復 |
|---|---|---|---|
| 正式版停用 source map | `.map` 不影響執行，卻佔發布容量 | 移除 98 個檔案，約 14.15 MB | 不影響玩家；線上除錯資訊較少，可移除 `GENERATE_SOURCEMAP=false` 回復 |
| 每次同步前重建 `site` | 舊雜湊 JS/CSS 持續累積 | 只保留最新且實際引用的發布檔 | 低；自動腳本限制只能清理專案內 `site` |
| `knowledge_base` 退出 Git 追蹤 | 已標示為本機研究語料且不屬於網站 | 新 clone／下載專案減少約 156.25 MB | 本機 260 個檔案完整保留；可由基準 tag 回復 |
| GitHub Actions 改用 `npm ci` | lockfile 已存在，應採確定性安裝 | CI 安裝更穩定、較快且不改依賴版本 | 低；lockfile 不一致時會明確失敗 |
| 保留路由分割與按需資源 | 關卡頁已使用 lazy chunks | 避免首頁一次載入所有關卡程式及媒體 | 沒有改動既有行為 |

## 需要人工確認

1. **影片有損壓縮**：影片約 172.08 MB，是發布容量的主要來源。可在新資料夾建立 H.264/AAC 相容版本，以 VMAF／SSIM、畫面並排及多裝置播放測試比較；預估可能再減少 20–50%。可能產生細節下降、色帶、音質差異或舊裝置相容問題，因此本輪不執行。
2. **移除版本庫中的 `site`**：GitHub Actions 已能直接部署 `build`，理論上可不再提交約 180 MB 的 `site`。目前 `site` 仍是分支型 Pages 的備援，直接移除可能讓 Pages 設定切換時回到 README，因此需先確認只使用 GitHub Actions Pages。
3. **未使用字型原始檔**：`src/asset/fonts/Regular.ttf` 約 21.44 MB，未進入正式 build。移除不會改善玩家下載，但能縮小本機素材；為避免它是設計原稿或未來動態用途，本輪保留。
4. **Git 歷史重寫**：目前 `.git` 仍含舊影片、研究 PDF 與歷史建置。`git filter-repo` 可大幅縮小 clone，但會改寫 commit SHA 並要求所有協作者重新 clone，故不直接執行。
