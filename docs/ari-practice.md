# ARI 正式評測前試玩

既有 `/test-ari` 頁面保留原本遊戲初始畫面與 STEP 影片介面，流程為「初始畫面 → STEP 影片 → 互動教學試玩 → 正式評測」。點擊「進入遊戲」顯示原 STEP 影片；影片結束、跳過或下一步後，直接透過 `AriPractice` 呈現試玩階段。通過並完整播放試玩通過語音後，點擊「開始挑戰」播放正式規則提醒；提醒播完才呼叫原本的 `startTest()`，開始正式評測與計時。正式題目、時限、計分及儲存維持原流程，結果畫面另播放完成語音。

## 題目與輪數

- 每組第一個聲音隨機選貓或狗，答對後一定換成另一種聲音。
- 貓叫選狗、狗叫選貓；連續兩題正確才通過。
- 任一題錯誤會重設連續答對次數，結束本組並重新隨機開始下一組。試玩畫面不顯示進度星星。
- `MAX_PRACTICE_ROUNDS = 3` 定義在 `src/components/AriPractice.jsx`。三組均未通過才顯示協助提示，因此每組最多兩題，總計最多六題。技術播放失敗及重播不計入輪數。
- 協助提示提供重新試玩與重看既有 STEP 影片；影片結束、跳過或下一步皆回到完整重設的試玩，不直接進正式測驗。
- 試玩答案僅存在元件記憶體，不呼叫正式評測紀錄、計分、localStorage 或資料庫 API。

## 狀態與聲音

`initializing → intro → dog_rule → cat_rule → question_prompt → stimulus_playing → answer_prompt → awaiting_answer → feedback`，之後進下一題、`completed` 或 `assistance_required`。答錯且尚可重試時，先經過 `retry_prompt`；通過後點擊「開始挑戰」，經 `assessment_intro` 播完提醒才離開試玩。

每段錄音必須收到 `ended` 才繼續。答對或答錯都播放對應語音，答錯後再播放重試提示；回饋至少維持一秒，且等待語音播完，期間鎖定作答與重播。最後一組失敗則播放答錯提示後顯示協助，不再要求重試下一題。重播只播放當題動物聲音，不重建題目。播放失敗、被瀏覽器擋下或逾時時，顯示「再播一次」並從失敗的錄音重試；不跳過刺激或完成錄音，也不重複累計答案與失敗輪數。卸載會取消聲音及所有試玩計時器。

依現有音檔套用下列語意相符的提示；部分句子與設計表措辭不同，使用既有錄音：

| 階段 | 實際錄音（`src/asset/voice/` 下的同名 `.mp3`） |
| --- | --- |
| 試玩開始 | 仔細聽喔！這次要找跟聲音不一樣的動物！ |
| 規則說明 | 聽到狗狗的叫聲，就要點貓咪！ → 聽到貓咪的叫聲，就要點狗狗！ |
| 開始操作（每題） | 小耳朵準備好！聽一聽，再點相反的動物！ |
| 聽完動物聲音 | 點擊你的答案 |
| 試玩答對 | 太棒了！你有找到正確的動物喔！ |
| 試玩答錯 | 哎呀！要點另一隻動物 |
| 試玩重試 | 沒關係，重新找另一隻動物！ |
| 試玩通過 | 太棒了！你學會找相反的動物了！ |
| 正式評測開始 | 記得喔！聽到聲音，要點另一隻動物！ |
| 正式評測結束 | 完成囉！你真的很努力！ |

正式評測題目進行中僅播放動物刺激，語音回饋與重播功能限於試玩。完成語音在結果儲存後播放，失敗時可點「重新播放完成語音」，不重複計分或儲存；離開結果頁會停止播放。

## 小雞旁白

所有旁白階段使用 `AriNarrator`，以 `chicken.webp`（張嘴）與 `chicken01.webp`（閉嘴）交替呈現說話。動畫由音訊的 `playing` 事件啟動，暫停、緩衝、播放結束、錯誤或取消時停止並閉嘴；等待載入時先顯示閉嘴小雞。動物叫聲及其重播不會觸發小雞。

- 開場、試玩通過與正式開始提醒：暫時收起動物與重播圖示，讓大雞置中；通過後的小雞閉嘴等待「開始挑戰」。
- 規則、題目前提示、作答提示與回饋：小雞使用獨立格位，寬螢幕放在貓狗中間並放大；窄螢幕放在動物上方。重播圖示放在遊戲畫面右上角，主體與操作區整體置中；上下保留相同空間，避免圖示遮擋角色。
- 試玩畫面不顯示上方標題或下方旁白字幕，也不保留標題／字幕的版面空間；相關文字以隱藏方式保留給螢幕閱讀器。
- 正式結果：小雞取代原狐狸位置，使用放大的獨立欄位，與星星、結果按鈕分開。播完後保留閉嘴小雞。
- 圖片置於一般版面流中且不接收點擊，避免覆蓋動物、手指提示與按鈕；減少動態效果偏好會停用嘴巴動畫。

全部素材以專案既有 import 打包：

- `src/asset/ARI/ARI_background.webp`、`cat.webp`、`dog.webp`、`cat.mp3`、`dog.mp3`
- `src/asset/mouse.webp`、`src/asset/voice.webp`
- `src/asset/chicken.webp`、`src/asset/chicken01.webp`
- 語音清單與 import 集中在 `src/utils/ariPracticeAudio.js`，對應上表。

`mouse.webp` 實際為手指引導圖，試玩可作答時指向正確的相反動物；通過後指向開始挑戰按鈕。動畫與版面樣式僅套用試玩階段。

## 驗證

`src/pages/ariPractice.test.jsx` 覆蓋開場與規則語音順序、兩種第一題、相反規則、答對／答錯／重試語音與最短回饋時間、連續答對計數重設、重播與重複提交、三輪協助、重新試玩、STEP 返回、音訊錯誤恢復、通過與正式提醒錄音鎖定、卸載與 StrictMode。

`src/pages/ariProtocolTiming.test.jsx` 經試玩與正式開始提醒後再驗證正式 20 題、5 秒時限、結果完成語音及錯誤恢復不重複存檔，並涵蓋原本的訓練規則。

實機還需確認瀏覽器的自動播放政策及手機／平板／電腦版面；若政策阻擋首段自動播放，使用畫面上的「再播一次」恢復。
