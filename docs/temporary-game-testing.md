# 臨時遊戲測試

在遊戲網頁的空白處，連續輸入三個半形句點 `...`，即開啟測試選單。每次按鍵間隔需小於 1.5 秒；輸入框、密碼欄或文字編輯區內不會觸發。

選單包含六款測驗，以及目前實作的全部訓練難度：SRT／PM／CBT／LB 各 5 關、ARI 3 關、DCCS 10 關；帽子遊戲可直接進入第 1～5 關。測驗保留原本的測驗規則；可選難度由訓練版本提供。

測試使用虛構兒童與記憶體快取。過程檢查點、正式結果歷史、同步佇列、訓練進度、金幣及貼紙不寫入瀏覽器儲存或雲端。每次從選單選關會清空上一關的預覽資料；「結束測試」重新載入首頁，清除全部測試記憶體。遊戲網址的 `gameTesting=1` 使重新整理後仍保持測試隔離。測試中只允許遊戲、遊戲結果及測試選單，其他導向回到測試選單。

完成全部遊戲開發後，先將 `src/config/featureFlags.js` 的 `ENABLE_TEMPORARY_GAME_TESTING` 改成 `false` 即可停用入口。要完全移除時，刪除 `src/temporaryGameTesting`，移除 App 中的測試選單／工具列／路由隔離，將遊戲頁、計分器及 LB 分析器的 storage adapter imports 還原成瀏覽器儲存，並移除 `resultManager`、`resultSync`、`useTestAttempt` 及帽子指定回合的測試分支。
