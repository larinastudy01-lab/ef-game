# 徽章通則（第 2 版）

每款遊戲各一枚成長徽章：SRT 橡實守護者、PM 圖片記憶家、CBT 石頭路記憶家、ARI 聲音反轉家、DCCS 規則切換家、LB 門牌導航員。

獲得規則統一為：**依系統推薦或醫療指定的難度，完整完成一次訓練，且正確率至少 80%，累積一次達標紀錄。** 每位兒童、每款遊戲、每個臺灣日曆日最多一次。可使用該難度原有提示，提醒次數保留於明細。

| 等級 | 累積達標次數 |
| --- | ---: |
| 銅級 | 1 |
| 銀級 | 3 |
| 金級 | 6 |
| 鑽石級 | 10 |
| 星耀級 | 15 |

等級代表持續達標的累積。每次達標及升階都保留當時難度，降級練習、後續失敗或一般歷史資料裁切都不會收回已獲得的徽章。正式評測、手動選擇未被推薦的難度、遊戲測試模式、中斷或未完成的場次不累積。

## 判定與保存

- `achievementProtocol.js` 是唯一判定來源。正確率依各遊戲既定計分結果，支援比例與百分比格式，不將 79.99% 四捨五入成達標。
- 訓練頁開始前透過 `useTrainingAchievementAssignment` 保留安排來源、兒童、遊戲、實際解析的難度與時間；完成結果必須與該安排一致。正常訓練地圖提供 `system_plan`，推薦入口提供 `system_recommendation`，沒有手動難度參數的預設入口提供 `system_default`。醫療指定可使用同一份 `trainingAssignment` 導航資料，來源為 `clinician`；本次不新增醫療處方操作介面。
- 完成結果需有明確的 `completed: true`，不能僅因統一結果預設狀態為 completed 就獲得徽章。CBT 依既定停止規則結束屬完整流程；PM 需完成既定輪數；LB 逾時結束保留進度，但不屬完整完成。
- `saveUnifiedResult` 在排除測試模式後保存徽章判定。相同結果重試不重複計數，同日其他合格結果不重複累積。
- `achievementProgress_v2_<childId>` 永久累積合格日與已獲得階級，不受原成就帳本 500 場上限影響。統一結果的 `rawResult` 保留 `achievementAssignment` 和 `achievementEligibility`，供同步及追查。成就頁可由已載入的合格結果恢復本機進度；目前沒有獨立的雲端徽章資料表。

## 舊制收藏

第一次載入新成就頁時，依既有成就帳本與舊結果計算已解鎖的舊徽章，將階級快照存入 `achievementLegacyAwards_v1_<childId>`。這些徽章在「舊制收藏」永久保留，不繼續按舊門檻升級，也不混入新制累積。新結果帶有安排或判定欄位，不參與舊制快照。

頁面顯示共同規則、距離下一階的達標次數，以及可展開的日期、難度、正確率與提醒紀錄。帽子遊戲的一般貼紙仍使用原收藏流程。
